# Product demo

The presentation uses a 2:02 real meeting recording supplied by Anuj Kumar Soni. The two camera feeds are real. Narration is generated by ElevenLabs using Midhun — Deep Indian Narrator. The original supplied recording has no audio track; the export adds the narration. No synthetic camera feed or Codex desktop footage is used in this version.

## Demonstration outline (approximately 3–5 minutes)

1. 0:00 — Problem: friction when getting a small study group connected.
2. 0:15 — Solution: a shared browser room link for up to four people.
3. 0:31 — Student identification.
4. 0:37 — Implementation: React/Vite, project-owned signaling and WebRTC.
5. 1:10 — Original supplied meeting footage, accompanied by device, invitation, chat and screen-sharing explanations.
6. 3:18 — Reliability and recovery design.
7. 3:52 — Leaving, recent rooms, temporary storage and scope.

The final export is approximately 4:21. Feature callouts describe the application; the supplied meeting footage does not show every workflow being exercised. Synthetic browser checks and physical-device reports remain documented separately in TESTING.md. The video does not imply exhaustive network verification.

The final public demo link is listed in `SUBMISSION.md` and the README once the video has been rendered and published.
